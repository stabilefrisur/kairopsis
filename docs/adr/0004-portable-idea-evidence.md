# Preserve idea evidence in portable folders

Each Idea has an application-managed folder containing readable notes, chart
images, underlying observations and saved analytical settings. Preserve dated
Snapshots alongside refreshing charts so an investment argument can be reviewed
independently of later data or analytical changes.

This uses more storage than retaining live chart definitions alone, but keeps
evidence that may be impossible to reconstruct. Versioned Ideas use atomic
commit pointers; Snapshots retain JSON, PNG and CSV records. Formats, backup
and recovery are documented in the [runtime guide](../runtime.md).
