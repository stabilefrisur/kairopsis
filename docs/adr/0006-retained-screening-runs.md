# Retain screening evidence before agent interpretation

Each completed refresh retains a Screening Run with the definitions, monitoring
membership, Economic Rationale, results and comparison evidence applicable to that
run. Publish the manifest only after its referenced evidence is complete. A mutable
latest-results pointer alone cannot support a reproducible brief after settings,
provider observations or saved research change.

Keep summaries small and full evaluation records separate within the run folder.
This duplicates retained evidence but allows a run to be copied and interpreted
without today's catalogue or the original workspace. Copy the displayed result
and its immediate comparison baseline, preserving original bytes; recursively
copying older comparisons would multiply storage across repeated runs. Distinguish processing
completion from observation freshness and preserve failed/retained results explicitly.

The dedicated screening skill orchestrates a new run or reviews a specified
existing run, then writes a Screening Brief. Kairopsis owns calculations and
retention; the agent supplies interpretation. Briefs are separate, versioned
outputs alongside immutable evidence. This uses the existing local deployment
and data-access decisions; it introduces no embedded agent service.
