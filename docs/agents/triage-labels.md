# Triage labels

Use these strings in issue files' `Status:` lines when triaging.

| Role | Status string | Meaning |
| --- | --- | --- |
| needs-triage | needs-triage | Maintainer evaluation needed |
| needs-info | needs-info | Waiting for more information |
| ready-for-agent | ready-for-agent | Fully specified; ready for an autonomous agent |
| ready-for-human | ready-for-human | Requires human implementation |
| wontfix | wontfix | Will not be actioned |

When a skill mentions a triage role, use its mapped status string.
Wayfinding ticket lifecycle states are defined in `issue-tracker.md`.
