# Subject resource boundary

Complete your case's REQUEST.md using the frozen skills. Read the Analysis entry
point before defining/interpreting an Analysis and Screening before reviewing a
retained run. Follow relevant references. These are offline fabricated fixtures.

Read only this file, your own case directory and the frozen skill folders. Source,
generator, private/, rubrics, other cases and previous results are outside scope.
No network, providers, delegation or external messages. Preserve fixtures and
skills; create working files only in your case's output/. A retained review may
save a new brief inside its run's briefs/ and must read it back. No configuration
or monitoring writes to any application are authorized.

If automatic execution review denies an action, report the denial and stop that
action; do not switch execution methods to bypass it.

After completion, save output/audit.json listing resources read, Analysis IDs
reviewed, evaluation/baseline IDs inspected, operations, output locations,
readback status and blockers. Return a concise result and artifact paths.
